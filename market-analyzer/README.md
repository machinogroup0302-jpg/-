# 相場分析ノート（自分専用 FX・株 分析サイト）

スマホで使うことを前提にした、自分専用のFX・日本株の分析サイトです。
iSPEED や LION FX のID・パスワードは使いません。すべてこのサイトの中で完結します。

## できること

| 画面 | 内容 |
|---|---|
| 全体 | 画面上の「**為替｜株**」で、為替と株を完全に分けて使える（お気に入り・見ている銘柄・取引履歴も別々） |
| | 専門用語には「**?**」が付いていて、押すとやさしい説明が出る。右上の「?」で用語集 |
| チャート | ローソク足チャート（5分〜週足）。移動平均・ボリンジャーバンド・一目均衡表・RSI・MACD を表示 |
| | **抵抗線・支持線・トレンドライン・ピボットを自動で引く**（価格の一覧つき） |
| | テクニカル分析の一覧（各指標を「買い／売り／中立」で判定し、総合判定） |
| | **予想チャート**（過去の値動きから2,000通りの未来をシミュレーションし、予想の中心と幅を表示） |
| | **AI予想（理由つき）**：今後1か月の重要な予定や**為替介入の可能性**をAIが調べ、予想の線と「なぜ上がる／下がるのか」の目印をチャートに書き込む（日足に表示。介入警戒の価格は赤い点線） |
| | **注文・約定分析（株）**：価格帯別出来高・買いと売りの勢い・出来高の急増・VWAP をグラフで表示。iSPEED の**板・歩み値のスクリーンショット**から、板の厚さ・約定の買い売り・大口約定もグラフ化 |
| 候補（為替） | 登録した通貨ペアを日足でまとめてチェックし、**可能性のある順にリスト化** |
| 候補（株） | **東証の全上場企業（約3,900社）**をまとめてチェック。上がりそう・下がりそう・**ストップ高・ストップ安**・値上がり・値下がりで並べ替え。市場・業種・値段で絞り込み |
| | 上場企業の一覧は日本取引所（JPX）の公開データを**毎日自動で確認**し、**新しく上場した会社・上場予定の会社**も表示 |
| チャート（株） | 今日の**ストップ高・ストップ安の値段**と、今どこまで動いているかを表示（チャートにも点線で表示） |
| ニュース | ニュースを自動収集し、**情報源・あおり表現・他媒体での裏付け**から信頼度を採点。怪しい情報は除外 |
| | **AIで詳しく調べる**：Web・SNSを検索し、噂を除外したうえで**ファンダメンタルズ分析**・今後の予定・見通しをまとめる |
| 取引分析 | 取引履歴の **CSV** または **スクリーンショット** を読み込み、勝率・損益比・最大ドローダウン・銘柄別・曜日別・時間帯別を分析。癖の指摘とAIコーチ |
| 画像分析 | iSPEED / LION FX のチャートのスクリーンショットをAIが分析し、**サポート・レジスタンス・トレンドラインを書き込んだ画像**を作る（保存可能） |

※ 分析や予想は参考情報です。将来の値動きを保証するものではありません。

## 公開のしかた（Render を使う例・無料プランあり）

1. https://render.com に GitHub アカウントで登録する
2. 「New +」→「Web Service」→ このリポジトリを選ぶ
3. 次のように設定する
   - **Root Directory**: `market-analyzer`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. 「Environment」に次を追加する
   - `SITE_PASSWORD` … このサイトに入るためのパスワード（**必ず設定してください**。未設定だとURLを知っている人は誰でも使えます）
   - `ANTHROPIC_API_KEY` … AI機能用のキー（任意。入れない場合はサイトの「設定」画面で入力）
   - `SESSION_SECRET` … 適当な長い文字列（任意）
5. 「Create Web Service」を押すと、数分で `https://〜.onrender.com` のURLができます

無料プランは、しばらく使わないとスリープし、最初の表示に30秒〜1分ほどかかります。

### スマホのホーム画面に追加する

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」

アプリのように全画面で開けます。

## AI機能について

画像分析・AIニュース分析・AIコーチは Anthropic の Claude API を使います。

- APIキーは https://console.anthropic.com で作成できます
- 使った分だけ料金がかかります（目安: 画像分析 1回 数円〜十数円、AIニュース分析 1回 数十円）
- 安全のための断りが出た場合は、自動で別のモデルに切り替えて続行する設定（`fallbacks`）を有効にしています

## パソコンで動かす場合

```bash
cd market-analyzer
npm install
SITE_PASSWORD=好きなパスワード npm start
# → http://localhost:3000
```

テスト: `npm test`

## データの取得元

- 価格: Yahoo Finance（為替は `USDJPY`、日本株は `7203` のように4桁コード、日経平均は `^N225`）
- ニュース: Google ニュース（直近7日）
- 取引履歴・設定・APIキー: 使っているスマホのブラウザ内だけに保存（サーバーには保存しません）

## 取引履歴CSVの出し方

- 楽天証券: パソコン版サイトの「口座管理」→「取引履歴」から CSV を保存
- ヒロセ通商（LION FX）: 会員ページやパソコン版の「取引履歴」「約定照会」から CSV を保存

メニュー名は変わることがあります。列名は自動で判別し、うまくいかないときは画面で割り当てを直せます。

## 自動更新

`market-analyzer` の中身を更新して GitHub に保存すると、GitHub Actions（`.github/workflows/render-deploy.yml`）が Render の Deploy Hook を呼び出し、数分で新しい版に入れ替わります。
Deploy Hook の URL は、GitHub の Secrets に `RENDER_DEPLOY_HOOK_URL` という名前で登録してあります。
